# Website Portfolio cá nhân

## Giới thiệu

Website giới thiệu thông tin cá nhân, kỹ năng,
quá trình học tập và form liên hệ.

## Công nghệ sử dụng

- HTML5
- CSS3
- SCSS
- JavaScript

## Cấu trúc

- index.html: Giao diện website
- css/style.scss: Mã nguồn SCSS
- css/style.css: CSS sau khi biên dịch
- js/script.js: Xử lý JavaScript
- js/data.json: Dữ liệu mẫu

## Cách chạy

1. Biên dịch SCSS:
   npx sass css/style.scss css/style.css

2. Mở index.html bằng Live Server.
